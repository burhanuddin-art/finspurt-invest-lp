# Finspurt Fortune 20: Google Ads landing page

Static landing page served by GitHub Pages at https://invest.finspurt.com

- `index.html`: the whole page. The `?ag=` parameter (brand, sebi, longterm, portfolio, advisor, services, pms, wealth) swaps the headline to match the Google Ads ad group.
- `CNAME`: custom domain for GitHub Pages.

To update the page, edit `index.html` and commit to `main`. GitHub Pages redeploys automatically.
